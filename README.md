# Tendies Cup skill for Bankr

Play [Tendies Cup](https://app.playtendiescup.fun), the fantasy trading league on Robinhood Chain, from your Bankr wallet.

Install by telling your Bankr agent:

    install the skill at https://github.com/thepegeek/tendies-cup-skill/tree/main/tendies-cup

Then say things like "enter the opening cup", "buy 10k of NVDA in tendies cup", "sell half my GME", "trades left", "leaderboard".

Docs: https://app.playtendiescup.fun/docs · API: https://app.playtendiescup.fun/api.md
